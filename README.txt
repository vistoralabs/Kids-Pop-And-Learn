# Kids Pop & Learn Developer Website

This is a static developer/support website prepared for Vercel.

## Important before publishing
Replace these placeholders in the HTML files:
- [DEVELOPER NAME]
- [DEVELOPER EMAIL]
- [PRIVACY EMAIL]
- [GOOGLE_PLAY_URL]

Do not change `app-ads.txt` unless your AdMob publisher information changes.

## Vercel
Upload this ZIP to https://vercel.com/drop
or import the files into a Git repository and deploy with Vercel.

After deployment, verify:
https://YOUR-VERCEL-DOMAIN/app-ads.txt

It must show exactly:
google.com, pub-5732060577215447, DIRECT, f08c47fec0942fa0
